= ライブマイグレーションが失敗しました

== シナリオ

ユーザーは `live migration` を使用して、仮想マシンをあるノードから別のノードに移行しようとしています。

NOTE: 主な目的は、ライブマイグレーションの失敗原因を調査し、是正措置を講じて仮想マシン `exercise6` を別のノードへ正常に移行することです。あなたの任務は、根本原因を特定し、問題を解決することです。

== ラボスクリプトの実行

この演習設定では、ユーザー `{user}` として OpenShift クラスターにログインしていることを確認してください。

.OpenShift ログインコマンド
[source,sh,role=execute,subs="attributes"]
----
{login_command}
----

OCP クラスターに接続したら、ラボを中断するコマンドを実行します。

.演習の中断
[source,sh,role=execute,subs="attributes"]
----
lab break exercise6
----
=== コンソール
中断後、ユーザー名とパスワードを使用して OpenShift Web コンソールにログインするか、踏み台サーバーで `oc` コマンドラインを使用してトラブルシューティングプロセスを開始できます。


link:{openshift_console_url}[{openshift_console_url}^]

.ユーザー名
[source,sh,role=execute,subs="attributes"]
----
{user}
----

.パスワード
[source,sh,role=execute,subs="attributes"]
----
{password}
----
