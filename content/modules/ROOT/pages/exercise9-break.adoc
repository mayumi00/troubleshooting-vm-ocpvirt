= ゲストOS内でシャットダウンを実行してもVMが停止しない

== シナリオ

仮想マシン `exercise9` は、ゲストOS内でユーザーが `shutdown -h now` コマンドを実行しても、シャットダウン状態を維持しません。シャットダウン処理完了後、数秒後に自動的に起動してしまいます。

NOTE: ゲストOSを使用してシャットダウンした後も仮想マシンが停止状態を維持するように、仮想マシンの設定を変更する必要があります。

== ラボスクリプトの実行

この演習では、ユーザー `{user}` としてOpenShiftクラスタにログインしていることを確認してください。


.OpenShift ログインコマンド
[source,sh,role=execute,subs="attributes"]
----
{login_command}
----

OCP クラスタに接続したら、コマンドを実行してラボを中断します。

.演習の中断
[source,sh,role=execute,subs="attributes"]
----
lab break exercise9
----

=== コンソール
中断後、ユーザー名とパスワードを使用して OpenShift Web コンソールにログインするか、踏み台サーバーの `oc` コマンドラインを使用してトラブルシューティングプロセスを開始できます。


link:{openshift_console_url}[{openshift_console_url}^]

.ユーザー名
[source,sh,role=execute,subs="attributes"]
----
{user}
----

.パスワード
[source,sh,role=execute,subs="attributes"]
----
{password}
