= 仮想マシンが起動しない - パート1

== シナリオ

ユーザーが仮想マシンを起動しようとしましたが、プロセスが正常に実行されませんでした。

++++
<a href="_images/exercise1/01-step2.png" target="_blank" class="popup">
++++
image::exercise1/01-step2.png[]
++++
</a>
++++

NOTE: このシナリオの主な目的は、障害の原因を調査し、`exercise1` 仮想マシンを `Running` 状態に戻すための是正措置を講じることです。このラボで使用する仮想マシンのメモリ容量は 8GB です。

あなたのタスクは、根本原因を特定し、問題を解決することです。

== ラボスクリプトの実行

この演習の設定では、ユーザー `{user}` として OpenShift クラスターにログインしていることを確認してください。


.OpenShift ログインコマンド
[source,sh,role=execute,subs="attributes"]
----
{login_command}
----

OCP クラスタに接続したら、コマンドを実行してラボを中断します。

.演習の中断
[source,sh,role=execute,subs="attributes"]
----
lab break exercise1
----

=== コンソール
中断後、ユーザー名とパスワードを使用して OpenShift Web コンソールにログインするか、踏み台サーバーの `oc` コマンドラインを使用してトラブルシューティングプロセスを開始できます。


link:{openshift_console_url}[{openshift_console_url}^]

ユーザー名
[source,sh,role=execute,subs="attributes"]
----
{user}
----

パスワード
[source,sh,role=execute,subs="attributes"]
----
{password}
----
