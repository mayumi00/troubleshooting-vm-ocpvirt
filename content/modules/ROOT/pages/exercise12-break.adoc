= 仮想マシン間の通信を有効にする - パート3

== シナリオ

仮想マシン `exercise12-a` と `exercise12-b` は、IPアドレスが正しく設定され、正常に動作しています。しかし、仮想マシン `exercise12-a` は、`exercise12-b` のポート80で実行されているアプリケーションにアクセスできません。

++++
<a href="_images/exercise12/12-break01.png" target="_blank" class="popup">
++++
image::exercise12/12-break01.png[]
++++
</a>
++++

[NOTE]
====
* 仮想マシン間の通信を妨げている問題を特定し、トラブルシューティングしてください。
* ポート80への接続を復元するために問題を解決してください。
* `subnet` は `NetworkAttachmentDefinitions` で定義されています。仮想マシンのIPアドレスを確認してください。
====

== ラボスクリプトの実行

この演習設定では、ユーザー `{user}` としてOpenShiftクラスタにログインしていることを確認してください。

.OpenShift loginコマンド
[source,sh,role=execute,subs="attributes"]
----
{login_command}
----

OCPクラスタに接続したら、ラボを中断するコマンドを実行してください。


演習の中断
[source,sh,role=execute,subs="attributes"]
----
lab break exercise12
----

=== コンソール
中断後、ユーザー名とパスワードを使用してOpenShift Webコンソールにログインするか、踏み台サーバーの `oc` コマンドラインを使用してトラブルシューティングプロセスを開始できます。

link:{openshift_console_url}[{openshift_console_url}^]

.ユーザー名
[source,sh,role=execute,subs="attributes"]
----
{user}
----

.パスワード
[source,sh,role=execute,subs="attributes"]
----
{password}
