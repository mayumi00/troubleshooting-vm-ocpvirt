= ラボ環境

[#lab]
== ラボの説明

このラボは、OpenShift Virtualizationにおける実際の問題をシミュレートし、一般的な問題のトラブルシューティングと解決に関する実践的な経験を提供するように設計されています。

== Bastion

このラボ環境内のすべてのスクリプトとコマンドは、バスティオンホストを介してSSH経由でのみ実行する必要があります。

== ラボスクリプト

`lab` スクリプトは、このラボで使用するツールです。`break`、`fix`、`grade`、`clean` の4つのオプションがあり、それぞれ特定の `<exercise>` に対して動作します。

=== 使用方法:

----
lab <オプション> <exercise>
----

=== オプション:

----
break
----

- 目的: `break` コマンドは、指定された演習に問題を導入します。これにより、解決すべき問題が演習に導入されます。

- 例: `lab break exercise1`

---- 
fix
----

- 目的: `fix` コマンドは、`break` によって発生した問題を解決し、演習を本来の動作状態に「復元」します。行き詰まった場合や、動作する例と自分の解答を比較したい場合に役立ちます。

- 例: `lab fix exercise1`

---- 
grade
----

- 目的: `grade` コマンドは、演習の解答を検証します。演習問題に基づいて正誤をチェックします。

- 例: `lab grade exercise1`

---- 
clean
----

- 目的: `clean` コマンドは、演習に加えた変更をすべて削除し、作成したリソースも削除して、演習を元の状態にリセットします。演習を最初からやり直したい場合や、再挑戦の準備をしたい場合に便利です。各演習を終えるたびに実行することをお勧めします。

- 例: `lab clean exercise1`

=== ワークフロー例:

. `lab break <exercise>` を実行して演習を開始します。

. 問題を手動で解決してみてください。

. `lab grade <exercise>` を実行して、解決した内容を確認します。

. 必要に応じて、`lab fix <exercise>` を使用して機能を復元するか、`lab clean <exercise>` を使用して手順 1 からやり直してください。
. 各演習の最後に、ラボをクリーンアップする必要があります。

== 仮想マシンへのアクセス

このラボのすべての仮想マシンは、ユーザーアカウント `lab-user` とパスワード `redhat1` * で設定されています。

_* exercise8 を除く_

注: 仮想マシンのオペレーティングシステムに変更を加えないでください。



== ガイド付きソリューション

このラボの最後には、すべての演習に対応したガイド付きソリューション（xref:guidedsolution.adoc[Guided Solution]）が用意されています。これを使って、問題を段階的に解決する方法を学ぶことができます。

* 演習の解決には、OpenShift Webコンソールと`oc`クライアントを使用します。

** GUIを使用すると、リソースとのインタラクションやタスクの実行をより視覚的に行うことができ、ポイント＆クリック操作を好むユーザーに最適です。

** ocクライアントはコマンドラインインターフェースを提供し、コマンドの実行やタスクの自動化において、より柔軟かつ制御性の高い操作を可能にします。

* どちらの方法でも、問題が解決されていることを確認できます。

== TMUX（ターミナルマルチプレクサ）

TIP: このラボでは、2つ目のターミナルを直接開く方法はありません。ただし、bastion環境では、ユーザーエクスペリエンスを向上させるためのカスタマイズがいくつかプリインストールされた`tmux`を使用できます。 `tmux`を起動するには、バスティオン端末で`tmux`と入力するだけです。

TIP: `tmux`内でコピー＆ペーストするには、マウスでコピーしたいテキストを選択し、`Ctrl + V`を押して貼り付けます。
