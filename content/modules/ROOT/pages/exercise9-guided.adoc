= ゲストOS内でシャットダウンを実行しても仮想マシンが停止しない

== シナリオ

仮想マシン `exercise9` は、ゲストOS内でユーザーが `shutdown -h now` コマンドを実行しても、シャットダウン状態を維持しません。シャットダウン処理完了後、数秒後に自動的に起動してしまいます。

NOTE: ゲストOSを使用してシャットダウンした後も仮想マシンが停止状態を維持するように、仮想マシンの設定を変更する必要があります。

=== コマンドライン (CLI)

1. ログインしていない場合は、割り当てられたユーザーアカウントを使用して `oc` コマンドで OpenShift サーバー API にログインします。

.OpenShift loginコマンド
[source,sh,role=execute,subs="attributes"]
----
{login_command}
----

[start=2]
2. 割り当てられたネームスペース{user}に移動します

[source,sh,role=execute,subs="attributes"]
----
oc project namespace-{user}
----

[start=3]
3. 仮想マシンの一覧を表示します

[source,sh,role=execute,subs="attributes"]
----
oc get vm
----

[start=4]
4. OSコマンドを使用して仮想マシンをシャットダウンします

[source,sh,role=execute,subs="attributes"]
----
virtctl ssh lab-user@exercise9 \
--command 'sudo shutdown -h now'
----

[start=5]
5.仮想マシンが停止し、数秒後に再び起動したことを確認します。

[source,sh,role=execute,subs="attributes"]
----
oc get vm
----

[start=6]
6. 仮想マシンを編集し、runStrategyを `always` から `manual` に変更します。

[source,sh,role=execute,subs="attributes"]
----
oc edit vm exercise9
----

[start=7]
7. OSコマンドを使用して仮想マシンを再度シャットダウンします。

[source,sh,role=execute,subs="attributes"]
----
virtctl ssh lab-user@exercise9 \
--command 'sudo shutdown -h now'
----

[start=8]
8. 仮想マシンが停止したままであることを確認してください。

[source,sh,role=execute,subs="attributes"]
----
oc get vm
----

=== 学習内容

この演習では、`runStrategy` が `Always` に設定されている場合、仮想マシンをオペレーティングシステムから直接シャットダウンできないことを学びました。シャットダウンするには、`runStrategy` の設定を削除するか、`Manual` に設定する必要があります。
