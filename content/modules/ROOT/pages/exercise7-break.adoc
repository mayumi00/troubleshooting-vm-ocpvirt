= 仮想マシンのスナップショット復元ボタンがグレー表示になっている

== シナリオ

このシナリオでは、`exercise7` という名前の仮想マシンが現在 `Running` 状態にあり、ユーザーが復元したい既存のスナップショットが存在します。しかし、ユーザーはスナップショットのボタンがグレー表示になっていることに気づき、復元を実行できない状態になっています。

あなたの任務は、ユーザーがスナップショットを復元するために行った手順を調査し、問題を解決することです。

NOTE: 目的は、仮想マシン `exercise7` のスナップショットを正常に復元することです。

== ラボスクリプトの実行

この演習設定では、ユーザー `{user}` として OpenShift クラスターにログインしていることを確認してください。

.OpenShift ログインコマンド
[source,sh,role=execute,subs="attributes"]
----
{login_command}
----

OCP クラスターに接続したら、ラボを中断するコマンドを実行します。

.演習の中断
[source,sh,role=execute,subs="attributes"]
----
lab break exercise7
----

=== コンソール
中断後、ユーザー名とパスワードを使用して OpenShift Web コンソールにログインするか、踏み台サーバーで `oc` コマンドラインを使用してトラブルシューティングプロセスを開始できます。
