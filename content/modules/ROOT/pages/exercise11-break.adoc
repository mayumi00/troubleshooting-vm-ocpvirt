[NOTE]
====
* VM間の通信を妨げている問題を特定し、トラブルシューティングしてください。接続を回復するために問題を解決してください。

* 必要に応じて、任意の仮想マシンを再作成できます。
* ゲストOS内の設定は一切変更しないでください。
====

== ラボスクリプトの実行

この演習では、ユーザー`{user}`としてOpenShiftクラスタにログインしていることを確認してください。

.OpenShift loginコマンド
[source,sh,role=execute,subs="attributes"]
----
{login_command}
----

OCPクラスタに接続したら、ラボを中断するコマンドを実行してください。


演習の中断
[source,sh,role=execute,subs="attributes"]
----
lab break exercise11
----
