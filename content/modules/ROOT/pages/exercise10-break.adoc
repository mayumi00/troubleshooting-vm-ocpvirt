[NOTE]
====
* VM間の通信を妨げている問題を特定し、トラブルシューティングを行うのがあなたのタスクです。

* 接続を回復するために問題を解決してください。

====

== ラボスクリプトの実行

この演習では、ユーザー `{user}` として OpenShift クラスターにログインしていることを確認してください。


.OpenShift ログインコマンド
[source,sh,role=execute,subs="attributes"]
----
{login_command}
----

OCP クラスタに接続したら、コマンドを実行してラボを中断します。

.演習の中断
[source,sh,role=execute,subs="attributes"]
----
lab break exercise10
----

=== コンソール
中断後、ユーザー名とパスワードを使用して OpenShift Web コンソールにログインするか、踏み台サーバーの `oc` コマンドラインを使用してトラブルシューティングプロセスを開始できます。


link:{openshift_console_url}[{openshift_console_url}^]

.ユーザー名
[source,sh,role=execute,subs="attributes"]
----
{user}
----

.パスワード
[source,sh,role=execute,subs="attributes"]
----
{password}
----
